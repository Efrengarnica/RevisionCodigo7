# Programa de Consulta de Capitales

Este programa permite consultar la capital de un país. Si la capital no está en la base de datos, el programa solicita al usuario que la ingrese y la guarda para futuras consultas.

## Funcionalidades Principales

- **Consulta de Capitales**: Permite al usuario ingresar el nombre de un país y devuelve la capital correspondiente si está en la base de datos.
- **Actualización de Datos**: Si la capital del país no está en la base de datos, el programa solicita al usuario que la ingrese y la guarda.
- **Interacción Continua**: El programa sigue preguntando por nombres de países hasta que el usuario ingrese "salir".

## Aprendizajes Clave

- **Uso de Scanner**: Utilización de la clase `Scanner` para leer entradas desde la consola.
- **Estructuras de Datos**: Uso de `HashMap` para almacenar y recuperar pares de país-capital.
- **Estructuras de Control**: Implementación de bucles `do-while` y condicionales `if-else` para la lógica del programa.
- **Manejo de Recursos**: Cierre adecuado del objeto `Scanner` para liberar recursos.

## Finalidad

El propósito de este código es practicar la lectura de entradas desde la consola, el uso de estructuras de datos como `HashMap`, y la implementación de lógica condicional para gestionar una base de datos simple de países y sus capitales. Es un ejercicio útil para entender los fundamentos de la programación en Java y la interacción con el usuario a través de la consola.
